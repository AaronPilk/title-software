# Agency feedback coverage — October 6, 2026

This checklist compares the Phase One Agency PDF and all seven customer beta-feedback entries available on October 6 against the implementation. It records capabilities and limits; it does not mark customer feedback resolved or claim customer acceptance. Production remains separate.

| Request | Implemented behavior |
| --- | --- |
| Simple internal workspace | Overview, Companies, Tasks and Documents are the everyday navigation. Additional workflows are secondary. External partner navigation/publication is absent from the ordinary staff path; existing authorization stays enforced. |
| Existing active companies | Existing operating status is preserved. Add company distinguishes existing active businesses from new joint ventures. No automatic checklist for an existing-company addition. |
| Useful company cards | Logo, states, underwriters, separate domain/email/website dates, open company tasks and document/member counts. Open company leads to its record. |
| Editable company details | Multiple labeled emails, primary email, address/domain/website, Website Not Needed, separate renewal dates/terms. Uploaded logo shows Change/Remove. |
| Completed application storage | Upload and retain is a complete action. It satisfies the generated received-application task; reading/import is optional. Private intake/status/link tools are collapsed. Application remains per Aaron's instruction. |
| Conditional setup | Versioned administrator-editable template; state, underwriter, individual/existing/new owner entity conditions; one combined or two governing agreements; required live original checks. Optional cards and delayed QuickBooks do not block activation. |
| Ownership and financial terms | Ownership and distribution percentages are distinct; management fee, effective date, source agreement(s) and totals are recorded. Private identifying/tax/payment metadata remains protected. No future payout calculations are implied. |
| Tasks | Company, assignee, status, due/completion dates, notes and source originals; company and work-type filters. Renewal rows open cycle completion or schedule management directly. |
| Dashboard attention | Required applicable licensing/approval work, confirmed standing problems, overdue tasks and near-term renewals. No manufactured historical application backlog for active companies. |
| File cabinet | Eight company folders, search/filter, upload, open/download, internal staff link, rename, move, current/final, recoverable Trash/restore. Referenced evidence and private originals retain removal safeguards. |
| Incorrect application removal | Originals linked only to the automatic received-application task can be trashed; setup recalculates from remaining originals. Other linked/private sources remain protected. |
| Recurring maintenance | Company, owner-entity and agency schedules; verification source/date, separate service dates, multi-year terms, completion history, next-cycle rollover. Overview service dates create tracking in the same save. |
| Renewal emails | Fourteen-day/overdue delivery, duplicate prevention, outbox history and authenticated scheduler are implemented. Workspace owner must still choose the shared reminder inbox and enable delivery. It remains disabled by default. |
| Screenshot feedback | Explicit PNG/JPEG attachment, preview/remove, private storage and report-author/owner access. No automatic screen capture. |
| Future workflows | Production, Missive and existing connectors are preserved. SoftPro access, financial integration and DocuSign send/completion import are separate later work, not requirements for storing an application. |

The detailed operating flow is in [Agency Phase One](agency-phase-one.md). The normal team path is **Companies → open company → details or documents**. New-venture setup and maintenance are used when applicable; advanced extraction, partner publishing and handoff work are not prerequisites.
